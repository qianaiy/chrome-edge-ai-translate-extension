译点 · 设置

直连你自己的 AI 接口。所有翻译请求从本机发出，不经过任何第三方服务器。

扩展后台还停在旧版本。 当前页面是 v，后台是 v， 所以新功能（比如拉取模型）会报「未知消息类型」。
去 chrome://extensions 找到「译点」，点一下卡片上的 刷新 ↻，再重新打开本页即可。

接口

自动识别会先按 Base URL 和模型名猜，猜错就换协议重试，成功后记住结果。填不准也能用。
只填域名也能用（比如 https://api.deepseek.com），路径会自动补全。
只存在本机 Chrome 的扩展存储里，不会同步到云端。Ollama 之类本地服务可以留空。
点「拉取模型」读取列表；之后点 ▾ 或输入框即可搜索选择，Esc 关闭后可手打模型名。
「测速」会发一个 8 token 的极短请求，量首字延迟和出字速度，用来判断某个模型现在快不快。
翻漫画需要能看图的多模态模型（如 gpt-4o、gemini-2.0-flash、qwen-vl）。留空就复用上面的模型。
视频没有字幕时，会录一小段声音送去识别。填支持音频的模型名（whisper-1 / gpt-4o-transcribe / gemini-2.0-flash）。留空就只用现成字幕。

整页翻译

单页应用（SPA）、无限滚动、点开评论区/展开更多这类后加载出来的内容，翻完页后会自动接着翻，不用再按一次快捷键。 关掉的话只翻按下快捷键那一刻页面上已有的正文。
不用记快捷键：点右侧那个「译」就能翻整页，翻完会变成「原」，再点一次还原。

自动翻译

打开后，访问英文、日文等非目标语言的网页时会自动整页翻译，不用按快捷键。
判断依据：先看网页自己声明的语言（<html lang>），没有的话看正文的文字构成。
已经是目标语言的网页不受影响，不会重复翻。文字太少的页面（登录页、报错页）也会跳过。
页面正文少于这个字数就不自动翻。默认 200 —— 太小了容易把登录页、报错页也翻一遍。
调成 0 就是不管多短都翻。

质量与风格

如果是技术文档，写上「术语保留英文原文」通常比换模型更能提升观感。

操作

扩展需要「读取你在所有网站上的数据」权限，因为划词和整页翻译必须注入页面。它不收集、不上传任何浏览数据； 唯一的外发请求就是你配置的那个 AI 接口。
